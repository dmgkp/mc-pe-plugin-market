# ChopTree(ChopTree)

## 功能简介

**ChopTree(ChopTree)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `0.2`,作者 ChalkPE。
主要功能方向:玩法。

## 权限点位

| 权限 | 说明 | 默认 |
|------|------|------|

1. 下载下方插件文件 `ChopTree-0.2.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
