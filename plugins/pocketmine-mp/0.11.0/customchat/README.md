# CustomChat(CustomChat)

## 功能简介

**CustomChat(CustomChat)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `1.1.2`,作者 [Praxthisnovcht]。
主要功能方向:聊天/公告、特效/粒子。
原插件说明:Adds options on the discution salon
本插件共提供 **9** 条命令(见下表)。

## 命令列表

| 命令 | 说明 | 用法 | 权限 | 别名 |
|------|------|------|------|------|
| `/setprefix` | 设置玩家称号 | `/setprefix` | customchat.plugin.setprefix | - |
| `/defprefix` | 设置默认称号 | `/defprefix` | customchat.plugin.defprefix | - |
| `/delprefix` | 把该玩家称号设置为默认称号 | `/delprefix` | customchat.plugin.delprefix | - |
| `/setnick` | 设置玩家昵称 | `/setnick` | customchat.plugin.setnick | - |
| `/delnick` | 还原为真实名称 | `/delnick` | customchat.plugin.delnick | - |
| `/mute` | 禁言玩家 | `/mute` | customchat.plugin.mute | - |
| `/unmute` | 解除禁言 | `/unmute` | customchat.plugin.unmute | - |
| `/disablechat` | 全体禁言 | `/disablechat` | customchat.plugin.offchat | - |
| `/enablechat` | 解除全体禁言 | `/enablechat` | customchat.plugin.onchat | - |

## 如何使用

1. 下载下方插件文件 `CustomChat-1.1.2.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
4. 在游戏内输入上表命令(控制台可省略 `/`)。
