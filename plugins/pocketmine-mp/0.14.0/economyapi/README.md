# EconomyAPI(经济核心插件)

## 功能简介

**经济核心插件(EconomyAPI)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `2.0.9`,作者 onebone。
主要功能方向:经济/商店、前置/API 库。
原插件说明:Allows to control all of functions in EconomyAPI
本插件未在 plugin.yml 中声明命令,可能通过 GUI / 物品 / 事件触发。
共定义 **1** 个权限点位(见下表,可用于判断插件能力)。

## 权限点位

| 权限 | 说明 | 默认 |
|------|------|------|
| `economyapi.*` | Allows player to take money from others | op |

## 如何使用

1. 下载下方插件文件 `EconomyAPI-2.0.9.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
