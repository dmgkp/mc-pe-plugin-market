# CustomChat(CustomChat)

## 功能简介

**CustomChat(CustomChat)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `1.3.2`,作者 [Praxthisnovcht]。
主要功能方向:聊天/公告、特效/粒子。
原插件说明:Adds options on the discution salon
本插件共提供 **9** 条命令(见下表)。

## 命令列表

| 命令 | 说明 | 用法 | 权限 | 别名 |
|------|------|------|------|------|
| `/setprefix` | sets prefix for player | `/setprefix` | customchat.plugin.setprefix | - |
| `/defprefix` | sets default prefix for new players | `/defprefix` | customchat.plugin.defprefix | - |
| `/delprefix` | set player's prefix to default | `/delprefix` | customchat.plugin.delprefix | - |
| `/setnick` | sets player's nick | `/setnick` | customchat.plugin.setnick | - |
| `/delnick` | returns players's real name | `/delnick` | customchat.plugin.delnick | - |
| `/mute` | mute player from chat | `/mute` | customchat.plugin.mute | - |
| `/unmute` | unmute player from chat | `/unmute` | customchat.plugin.unmute | - |
| `/disablechat` | disable chat for all players | `/disablechat` | customchat.plugin.offchat | - |
| `/enablechat` | enable chat for all player | `/enablechat` | customchat.plugin.onchat | - |

## 如何使用

1. 下载下方插件文件 `CustomChat-1.3.2.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
4. 在游戏内输入上表命令(控制台可省略 `/`)。
