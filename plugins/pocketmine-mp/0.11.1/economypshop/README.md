# EconomyPShop(经济)

## 功能简介

**经济(EconomyPShop)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `2.0.0`,作者 onebone。
主要功能方向:经济/商店、管理/权限。
原插件说明:Allows all permissions to the player
本插件未在 plugin.yml 中声明命令,可能通过 GUI / 物品 / 事件触发。
共定义 **1** 个权限点位(见下表,可用于判断插件能力)。

## 权限点位

| 权限 | 说明 | 默认 |
|------|------|------|
| `economypshop.*` | Allows player to destroy others' shop | true |

## 如何使用

1. 下载下方插件文件 `EconomyPShop-2.0.0.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
