# TPALL(简单传送)

## 功能简介

**简单传送(TPALL)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `1.2.0`,作者 PiZzle_zZau。
主要功能方向:世界/传送。
原插件说明:传送所有人到自己身边
