# FactionsPro(配套插件)

## 功能简介

**配套插件(FactionsPro)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `1.4.1`,作者 Tethered_, HostingItAll.com。
主要功能方向:玩法。
原插件说明:A Plugin For Easily Managing Factions
本插件共提供 **1** 条命令(见下表)。
共定义 **2** 个权限点位(见下表,可用于判断插件能力)。

## 命令列表

| 命令 | 说明 | 用法 | 权限 | 别名 |
|------|------|------|------|------|
| `/f` | use /f help for all parameters | `/f` | f.command | - |

## 权限点位

| 权限 | 说明 | 默认 |
|------|------|------|
| `f.command` | Allow use of all faction commands | true |
| `fac.override` | Allows op users to override factions | op |

## 如何使用

1. 下载下方插件文件 `FactionsPro-1.4.1.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
4. 在游戏内输入上表命令(控制台可省略 `/`)。
