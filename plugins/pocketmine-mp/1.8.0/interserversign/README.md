# InterServerSign(跨服最新版)

## 功能简介

**跨服最新版(InterServerSign)** 是一款运行于 **PocketMine-MP** 的 Minecraft 基岩版插件,插件版本 `2.1.1`,作者 MUedsa。
主要功能方向:玩法。
原插件说明:InterServerSign
本插件未在 plugin.yml 中声明命令,可能通过 GUI / 物品 / 事件触发。
共定义 **2** 个权限点位(见下表,可用于判断插件能力)。

## 权限点位

| 权限 | 说明 | 默认 |
|------|------|------|
| `interserversign.sign.build` | only op can build the sign | op |
| `interserversign.sign.tp` | Allows the user tp another server | true |

## 如何使用

1. 下载下方插件文件 `InterServerSign-2.1.1.phar`。
2. 放入服务器 `plugins/` 目录(PocketMine-MP)。
3. 重启或重载服务器,插件会自动加载。
